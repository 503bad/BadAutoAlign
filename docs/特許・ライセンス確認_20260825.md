### 1.4 ガイド音声へのタイミング整合 — **要注意（中）**
| 特許 | 状態 | 備考 |
|---|---|---|
| US 4,591,928（Bloom / Wordfit、1983） | 失効 | |
| **US 7,825,321 B2**（Synchro Arts、2005） | **有効（〜2029-09）** | ガイドと新信号の時間整合パスを求め、それを使ってガイドの特徴（ピッチ等）を新信号へ転写。「整合＋ガイド特徴の転写」を同時に行うと近い |
| **US 12,334,104 B2**（Synchro Arts、2021。EP 4377958 / WO 2023/007173） | **有効（〜2043）** | 整合前にフレームを matchable / unmatchable（有声・無声、ノイズフロア）に分類し、matchable 区間にのみ整合パスを適用してタイミング／ピッチ／ラウドネスを修正 |
| US 9,111,580（Harman、2011） | 有効（〜2033） | 包絡＋相互相関で 2 録音の**大域**時間シフトを求める。本製品は局所ラグの区分線形ワープで目的が異なるが手法は重なる |
| Dolby US 7,461,002 / AudioCodes US 8,296,131 | 失効 | |
| P-center（知覚的中心） | 学術文献のみ（Morton/Marcus 1976, Scott 1993）。特許なし | |

**本製品との関係:**
- WAV ガイド経路は「包絡相互相関で整合 → タイミング修正 → ノート単位のピッチオフセット補正」で、
  US 7,825,321 の「整合パスによる特徴転写」に構成上近い。`--pitch-target curve`（ガイド F0 カーブ転写）は特に近い。
- 子音保護・伸縮再配分（有声／無声で扱いを変える）は US 12,334,104 の「matchable 分類」と概念的に隣接。
- MIDI ガイド経路（整合パスなし、ノート音高への補正）は両クレームから遠い。

**推奨:** 販売前に上記 2 件（および JP/EP 対応出願）についてクレームチャート照合を弁理士に依頼する。
対策候補: `curve` モードの既定無効化、整合と特徴転写の分離設計の明文化。

### 2.2 同梱コンポーネントとコピーレフト
コピーレフトは「弱い」LGPL のみ。**強いコピーレフト（GPL）は含まれない。**

| コンポーネント | ライセンス | 義務・対応 |
|---|---|---|
| libsndfile（python-soundfile 経由） | LGPL-2.1+ | 独立 DLL として同梱（差し替え可）、全文・表記・ソース入手先を `THIRD_PARTY_NOTICES.md` に記載 → **対応済み** |
| python-soxr / libsoxr（librosa 依存） | LGPL-2.1+ | 独立 `.pyd`（差し替え可）、同上 → 対応済み |

| certifi | MPL-2.0 | 改変せず同梱。ファイル単位の弱いコピーレフトで義務は表記のみ |

**onefile 形式にはしないこと**（LGPL の差し替え要件を満たしにくくなる）。
