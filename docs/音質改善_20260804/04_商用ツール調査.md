# 04. 商用ツール調査 — Melodyne / Vovious / Auto-Tune / élastique / VocALign

公開情報（設計記事・特許・レビュー・SDK ドキュメント）から読み取れる範囲で、
商用ツールが品質のために行っていることを整理する。内部実装は非公開のため、
一部は挙動からの推定であることに注意。

## 1. Melodyne（Celemony）

- **ノート単位の分解**: 音声をノート（blob）に分解し、ノートごとに
  ピッチ中心・ドリフト・ビブラート（pitch modulation）・フォルマント・振幅を
  **独立に編集可能なパラメータ**として保持する。単なる F0 カーブ操作ではなく、
  「ノートモデル」への分解が本質。
- **補正の分離**: 「ピッチセンター補正」と「ピッチモジュレーション（揺らぎ）補正」が
  別スライダーになっている。センターだけ動かせば揺らぎは完全保存される
  （→ 03 §5.1 の成分分解と同じ思想）。
- **タイミング補正**: ノートのアタックを基準に移動し、**持続部の伸縮で辻褄を合わせる**。
  トランジェント位置は保護される（→ 02 §3.1）。
- **信号処理**: 挙動（モノフォニックでの透明性、フォルマント独立操作）から、
  ピッチ同期の分析再合成（サイン成分＋残差、PSOLA 類似のローカル再合成）と推定される。
  ポリフォニック対応（DNA）は倍音群のクラスタリングによるノート分離。

**本プロジェクトへの示唆**: ノートモデル化（センター/揺らぎ/アタック保護の分離）は
現行の設計（中央値オフセット＋アタックランプ）と方向が一致。差分は
ドリフト処理・遷移同期・タイミングの「持続部吸収」。

## 2. Vovious（2025年12月登場）

- 「Natural-sounding vocal tuning software backed by cutting-edge (AI)」を掲げる新興ツール。
  UI 操作は Melodyne / RePitch 類似だが、補正結果の自然さが評価されている。
- 公開情報が少ないが、レビュー記事では「従来と根本的に異なる仕組み」
  「ボーカルディレクション（歌い方の編集）の領域」と評されており、
  ニューラル再合成（SVC/DDSP/拡散モデル系）を用いた声質保存シフトと推定される。
- 示唆: 最終品質の天井はニューラル系にあるが、依存とライセンス、オフライン配布の制約が
  大きい。本プロジェクトでは Phase 4 の研究項目とする（05 §4）。

## 3. Auto-Tune（Antares）

- リアルタイム系。位相同期のピッチ検出＋低遅延シフト（PSOLA 系と推定）。
- Retune Speed が唯一の自然さパラメータで、速すぎる吸着がいわゆる「ケロケロ」。
  自然運用では 20〜50ms 程度の時定数＋Humanize（持続部の吸着緩和）。
- 示唆: 「吸着の時定数」と「持続部での強度緩和」はカーブ設計に直接輸入できる。

## 4. zplane élastique（多くの DAW の標準エンジン）

- Pro 版は「フェージングアーティファクトなしで音声の明瞭度を維持」
  「モノ/ポリ両対応のフォルマント保持」「トランジェント保持」を明記。
  時間・周波数両領域でトーナル成分とトランジェント成分を検出し分離処理する
  （→ 02 §1.4 のハイブリッド TSM と同じ枠組み）。
- SOLOIST モードはモノフォニック特化（PSOLA 系）で、単独歌声にはこちらが使われる。
- 示唆: 「トランジェント検出→分離処理」は業界標準の品質要件。
  現行実装に欠けている最大の要素と一致する。

## 5. VocALign（Synchro Arts）/ Revoice Pro

- ガイドとの**エネルギー包絡の時間対応**を DTW で求め、可変レートストレッチで追従させる。
  本プロジェクトの `_xcorr_lag_samples`（局所相互相関）と同系統の前段。
- Revoice Pro の APT は ピッチ・レベル・タイミングを同時転写。タイミングは
  「Protected 区間」（伸縮しない区間）をユーザーが指定できる — トランジェント保護の明示 UI。
- 示唆: ラグ推定は現行実装で既に VocALign 相当の枠組み。差は伸縮の適用側の品質。

## 6. 横断的な結論

商用ツールに共通する品質要素は次の4点に集約される:

1. **トランジェント/アタックの保護**（全ツール共通）
2. **フォルマント保持**（全ツール共通）
3. **補正対象の成分分離**（センター vs 揺らぎ、トーナル vs トランジェント）
4. **持続部・無音での辻褄合わせ**（伸縮の再配置）

これらはすべて現行アーキテクチャの延長で実装可能であり、
ニューラル化しなくても「商用ツール的な自然さ」の大半に到達できる。
