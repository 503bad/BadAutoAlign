# 音質改善プロジェクト（2026-08-04）

本ディレクトリは、vox_fix（ボーカル自動ピッチ/タイミング補正ツール）の音質課題を解決するための
調査・設計・工程ドキュメント群である。

## 対象の課題

1. **タイミング補正箇所の「バリバリ」音**
   引き伸ばし（タイムストレッチ）による不自然な音質劣化。トランジェントの滲み・位相の濁り・
   レート急変によるフレーム不連続が原因（詳細は `01_現状分析.md`）。
2. **ピッチ補正の品質**
   Melodyne / Vovious 等の商用ツールが備える「自然に聞こえるための処理」
   （フォルマント保持・ビブラート/ドリフト分離・遷移の扱い等）が欠けている。

## 結論の要約（先に読む人向け）

- バリバリ音の主因は「エンジンそのもの」ではなく **ワープのレート変化点が母音の芯に置かれる設計**と
  **トランジェント（子音）が伸縮対象に含まれる**こと。Signalsmith Stretch は可変レートに対応しているが、
  知覚的に敏感な位置でレートが折れ曲がる限り品質は上がらない。
- 対策の柱は3つ:
  (a) **伸縮の再配置** — 子音・アタックはレート1.0で保護し、母音持続部と無音で伸縮を吸収する
  （Melodyne 方式。既存のワープマップ構築段階で対応可能）
  (b) **フォルマント保持の有効化** — ラッパーに既にバインド済みの `vs_set_formant_factor` を使う
  (c) **補正カーブの高度化** — ビブラート/ドリフト分離、ノート遷移モデル、tonality limit
- 工程は4フェーズ。Phase 1（伸縮再配置＋フォルマント保持）だけで体感品質の大部分が改善する見込み。
