# 02. 理論 — タイムスケール変更（TSM）と「バリバリ音」を消すための手法

タイミング補正の実体は局所的なタイムスケール変更（Time-Scale Modification, TSM）である。
本書は TSM の主要方式と、その品質劣化（アーティファクト）の発生機構、
歌声に対して品質を上げるための既知の手法を整理する。
主要な出典は Driedger & Müller のレビュー論文（→ 08_参考文献）。

## 1. TSM 方式の分類

### 1.1 時間領域方式: OLA / SOLA / WSOLA

波形をフレームに切り、合成側で間隔を変えて重畳加算する。
WSOLA (Waveform Similarity OLA) は貼り付け位置を波形相関が最大になる位置へ微調整して
周期の連続性を保つ。

- 長所: トランジェントが比較的鮮明。計算が軽い。位相の濁りがない。
- 短所: 有声音で貼り合わせ周期の誤りがあると「ダブり」「揺れ」。
  ポリフォニックに弱い（歌声モノフォニックでは問題になりにくい）。

### 1.2 位相ボコーダ (Phase Vocoder, PV)

STFT フレームの合成間隔を変え、各ビンの位相を瞬時周波数に基づいて進める。

- **水平インコヒーレンス（phasiness）**: ビンごとに独立に位相を進めると
  ビン間の位相関係（垂直コヒーレンス）が崩れ、リバーブ感・「芯のない」音になる。
  対策: Laroche & Dolson の **identity phase locking**（スペクトルピークを検出し、
  ピーク周辺ビンの位相をピークに追従させる）。
- **トランジェント滲み**: 打撃・破裂音のエネルギーが窓長ぶんの時間に拡散する。
  対策: **phase reset**（トランジェント検出時に合成位相を分析位相にリセットし、
  トランジェント近傍はレート1.0で通す）。

### 1.3 ピッチ同期方式: TD-PSOLA / ESOLA

ピッチマーク（声門閉鎖時点）を検出し、2周期長の窓で切り出したグレインを
新しい間隔で再配置する。モノフォニック音声では最高品質級のタイム/ピッチ変更が可能で、
フォルマント（包絡）が自動的に保存される。

- 長所: 有声音の自然さ・フォルマント保持・低レイテンシ。
- 短所: ピッチマーク誤りに敏感。無声音・息成分はザラつく（無声部は別処理が必要）。

### 1.4 ハイブリッド: HPSS-TSM（Driedger）

調波打楽器音分離（HPSS）で信号を調波成分と打撃（トランジェント）成分に分け、
**調波成分は大きな窓の位相ボコーダ、打撃成分は極小フレームの OLA** で伸縮して合算する。
単独方式より一貫して高品質で、商用エンジンに匹敵すると報告されている。
歌声では「母音＝調波」「子音＝打撃的」に対応し、そのまま有効。

### 1.5 分析再合成: WORLD 等のボコーダ

F0・スペクトル包絡・非周期性に分解し、フレーム列を時間方向にリサンプルして再合成する。
伸縮自体は完璧（滲みなし）だが、モデル化誤差（buzzy 感）が常時乗る。

### 1.6 Signalsmith Stretch（現行エンジン）の位置づけ

設計記事によれば、標準 PV と異なり**入力の近傍位相関係（時間方向＋周波数方向）を測定し、
出力で同様の関係を再構築する**方式。スペクトルピーク周辺は 1:1 スケーリングを保つ
非線形周波数マップを併用し、phasiness を大きく抑えている。
既知の限界として、大きな伸縮では垂直位相スケーリングを 2x で制限し
ランダム化を混ぜるため「juddery smudge」（にじみ）が出る。
→ エンジンとしては現代的で優秀。**品質問題の主因はエンジンではなく使い方**（01 §2）。

## 2. アーティファクト発生機構の整理

| アーティファクト | 聴感 | 機構 | 主な対策 |
|---|---|---|---|
| phasiness | リバーブ感・芯がない | ビン間位相の崩れ | phase locking（Signalsmith は対策済み） |
| transient smearing | 子音がバリッ/モヤッ | 窓長への拡散 | phase reset / トランジェント保護区間 |
| レート不連続 | 周期的なざらつき・段差 | 合成間隔の急変で位相進行が乱れる | レートの連続化・折れ点の再配置 |
| 波形不連続 | クリック/バリバリ | チャンク境界のサンプル欠落・スキップ | ストリーム処理の連続性保証 |
| ダブり(WSOLA) | エコー | 貼り合わせ周期誤り | 相関窓の適正化 |
| buzzy(ボコーダ) | ブザー的 | 励振モデル誤差 | 非周期性推定の改善・残差保持 |

「バリバリ」という表現は上表の **transient smearing ＋ レート不連続 ＋ 波形不連続** の
複合に典型的である。

## 3. 歌声タイミング補正に特化した高品質化手法

### 3.1 伸縮の再配置（elasticity mapping）— 最重要

ワープマップは「どの時刻をどこへ動かすか」しか規定しない。
**同じ到達位置でも、途中のレート配分は自由**である。品質を決めるのはレート配分であり、
原則は次の通り:

1. **無音・息継ぎ区間で最大限吸収する**。無音の伸縮は知覚されない。
2. **無声子音（摩擦・破裂）はレート 1.0 で保護**し、前後の母音持続部と無音に配分する。
   Melodyne がノート移動時に行っているのは実質これ（ノートの「アタックを保ったまま
   持続部で辻褄を合わせる」）。
3. **母音内部でレートを変えるなら、折れ点を作らず C1 連続（傾き連続）に**する。
   区分線形ではなく、単調 3 次エルミート（PCHIP）等でレートカーブを滑らかにする。
4. 芯（P-center）が目標時刻に合うことが唯一の制約。芯の直近でレートが変わる必要はない。

現行実装は逆に「芯にアンカー（折れ点）を置き、子音を伸縮し、無音は端の余白でしか使わない」
構成であり、ここを反転させるのが最大の改善である。

### 3.2 トランジェント検出

保護区間を決めるためのトランジェント検出は、歌声では以下が実用的:

- スペクトルフラックス（高域重み付き）のピーク検出
- 有声/無声判定（既存の pYIN voicing）との併用: 無声→有声遷移点＝子音→母音境界
- 既存の `syllables.py`（音節検出）と `pcenter.py`（芯検出）の出力をそのまま利用可能

### 3.3 伸縮率の抑制

同じ移動量でも、吸収区間を広く取るほど局所レートは 1.0 に近づく。
max_shift=120ms をフレーズ内の無音＋母音持続部全体に分配すれば、
局所レートは 0.9〜1.1 程度に収まり、位相ボコーダの劣化がほぼ知覚されない領域に入る。
ガード（現行 0.25〜4.0）は 0.7〜1.5 程度まで狭めるべきである。

### 3.4 ストリーム駆動の連続性

チャンク駆動は残すとしても:

- チャンク長をレート変化の時定数より十分小さく（例: 256〜512 サンプル）
- 出力要求数の丸めは誤差を持ち越す（`emitted` 累積との差分で要求。現行実装は既にこの形だが、
  スキップ分岐で入力が欠落しないことを保証する）
- レートはチャンクごとに階段でなく、目標レートカーブをチャンク中心で標本化

### 3.5 将来オプション: 方式ハイブリッド

- **HPSS-TSM**: librosa の HPSS ＋ 現行 Signalsmith（調波）＋ OLA（打撃）。
  実装コストは中程度で、子音品質の底上げになる。
- **有声部 TD-PSOLA**: 検出済み F0 があるためピッチマーク推定は容易。
  モノフォニック歌声では最高品質だが、実装・調整コストが高い。Phase 3 以降の選択肢。
