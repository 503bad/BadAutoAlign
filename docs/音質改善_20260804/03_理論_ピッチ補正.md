# 03. 理論 — ピッチシフトの高品質化と「自然な補正」のためのカーブ設計

ピッチ補正の品質は2層に分かれる:

- **信号処理層**: 決められた量のシフトを、いかに劣化なく音に適用するか（§1〜4）
- **音楽的な層（補正カーブ設計）**: そもそも「いくら・どの形で」シフトするのが自然か（§5）

商用ツールとの差は両層にあり、後者が軽視されがちだが知覚上は同等以上に重要。

## 1. フォルマント保持（最重要）

声道の共鳴（フォルマント）はスペクトル包絡として現れる。素朴なピッチシフトは
包絡ごと周波数軸を移動させるため、上げると「チップマンク声」、下げると「こもった声」になる。

**原理**: ピッチシフトを「調波構造の移動」と「包絡の維持」に分離する。

1. スペクトル包絡を推定する
   - LPC（軽量・歌声では次数依存）
   - ケプストラム / True Envelope（調波間の谷を拾わない反復推定。高品質）
   - WORLD CheapTrick（F0 適応窓で包絡推定。歌声で実績）
2. シフト後のスペクトルに元の包絡を再適用する（包絡比のフィルタリング）

**現行コードでの位置づけ**: Signalsmith Stretch は `setFormantFactor` /
`setFormantSemitones`（ラッパーでは `vs_set_formant_factor`）でこれを内蔵しているが、
現在未使用（01 §3 原因 F）。`formant_factor=1.0`（フォルマント固定）を指定するだけで
包絡保持シフトになる。加えて `setFormantBase` 相当で基準 F0 を与えると包絡推定が安定する
（wrapper.cpp の API 拡張が必要なら追加する）。

**知覚上の目安**: ±50 セント以下ではフォルマント移動はほぼ知覚されない。
±100 セントを超えると明確に声質が変わる。max_correction_cents=300 の現行仕様では必須。

## 2. tonality limit（高域の非調和成分の扱い）

子音・息・ブレスの高域はピッチを持たない。これらまでスケールすると
「シュワシュワした」不自然さが出る。Signalsmith Stretch の tonality limit は
コーナー周波数以上を 1:1 に保つ非線形周波数マップで、設計記事では
コーナーを √factor で補正する（入力と出力の妥協点）。
歌声では 6〜8 kHz / √factor 程度が実用的な初期値。

## 3. ピッチシフト方式の比較（歌声・モノフォニック前提）

| 方式 | フォルマント | トランジェント | 質感 | 備考 |
|---|---|---|---|---|
| PV + phase locking（Signalsmith） | オプションで保持 | やや滲む | 現代的・良好 | 現行。設定次第で大幅改善 |
| TD-PSOLA | 自動的に保持 | 鮮明 | 有声部は最高級 | ピッチマーク精度が命。無声部は素通しにする |
| WORLD | 包絡分離で保持 | 再合成で劣化 | buzzy 上限 | 大シフトでも破綻しにくい |
| ニューラル（SVC/diffusion/DDSP） | 学習で保持 | 良好 | 最高品質の可能性 | 依存・ライセンス・再現性のコスト大 |

**結論**: 現行の Signalsmith を正しく設定（フォルマント＋tonality）するのが費用対効果最大。
TD-PSOLA は Phase 3 以降の選択肢（02 §3.5 と共通基盤）。

## 4. WORLD エンジンの品質限界と改善余地

- buzzy 感の主因は D4C の非周期性推定誤差と、励振モデル（調波＋帯域ノイズ）の表現力上限。
- 改善余地: (a) 無声/摩擦区間は原音をそのまま通す（re-synthesis しない）、
  (b) フレーム周期を 5ms→2.5ms、(c) 高 SNR 帯域の位相を原音から継承するハイブリッド合成。
- ただし WORLD はフォールバックエンジンであり、投資優先度は低い（01 §4 対応 E）。

## 5. 「自然な補正カーブ」の理論 — 商用ツールが行っていること

### 5.1 F0 軌跡の成分分解

歌声の F0 軌跡は次の成分の和としてモデル化できる:

```
F0(t) = ターゲット音高(ノート) + 遷移成分(しゃくり・ポルタメント)
        + ビブラート(4〜7Hz) + ドリフト(〜2Hz のゆっくりした逸れ)
        + ジッタ(マイクロ揺らぎ >8Hz)
```

自然な補正とは「**ドリフトと恒常オフセットのみを除去し、
遷移・ビブラート・ジッタを保存する**」こと。全成分を潰すと Auto-Tune 的ロボット声になる。

実装的には F0 誤差信号（検出F0 − ターゲット）を周波数帯域で分離する:

- 0〜2Hz 成分（オフセット＋ドリフト）→ 補正ゲイン 1.0
- 4〜7Hz 成分（ビブラート）→ 補正ゲイン 0（保存）。深すぎる場合のみ振幅を軽くスケール
- 高域（ジッタ）→ 補正ゲイン 0（保存）

現行実装は「ノート中央値オフセットのみ補正」でビブラート保存は達成しているが、
ドリフトが残る（01 §3 原因 H）。ローパスした誤差カーブを引く方式に拡張すると
ノート内の逸れも直り、かつ揺らぎは保存される。

### 5.2 ノート遷移（しゃくり・ポルタメント）の扱い

- ノート境界の補正量ジャンプは、そのまま適用すると F0 に段差を作る。
  現行のガウシアン平滑（σ=40ms）は有効だが、**遷移の時間位置**が
  歌唱の遷移タイミングとずれると「二重の遷移」に聞こえる。
- 改善: 検出 F0 の変化率が最大の時刻（歌い手の遷移中心）に補正量の遷移を同期させ、
  遷移幅も歌唱の遷移幅に合わせる（S字＝raised-cosine 遷移）。
- 現行の attack_preserve_ms（80ms ランプイン）はしゃくり保存として正しい方向。
  遷移同期はその一般化にあたる。

### 5.3 スケール/ガイドへの吸着強度

pitch_strength（現行 0.85）による部分吸着は正しい設計。加えて商用ツールは
- 補正量に応じた非線形（小さいズレはほぼ全部直し、大きいズレは比例的に残す）
- ノートごとの信頼度による強度変調
を行う。ランダムさが残ることが「人間らしさ」の鍵。

### 5.4 検出品質の底上げ

カーブ品質は検出品質が上限になる。
- RMVPE / CREPE は pYIN よりオクターブ誤りに強く、低 SNR・かすれ声に頑健。
  既にコード上の選択肢があるため、モデル同梱のうえ既定化する価値が高い。
- 後処理: メディアン→Viterbi 平滑、サブハーモニクス飛びの検出
  （倍/半への瞬間ジャンプをピッチクラス整合で棄却。timing.py の
  `_anchor_pitch_ok` と同種のロジックを検出後処理へ展開）。

### 5.5 タイミング補正との相互作用

ピッチシフトとタイムワープを別パスで直列適用すると、劣化が2回乗る。
Signalsmith Stretch はストリーミング API で**レートとトランスポーズを同時に**変えられるため、
ワープとピッチシフトを1パスに統合すれば、STFT 分析・再合成が1回で済み、
劣化・処理時間とも半減する（現行は time_warp 後に再検出が必要なため2パスだが、
補正カーブを「ワープ後時間軸に写像」すれば1パス化できる。→ 05_改修方針 §3）。
