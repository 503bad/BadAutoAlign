# 商用ライセンス購入の検討対象（予算検討用）

最終更新: 2026-07-17

## 前提: 現行構成に購入必須のものは無い

現在のVocalAlignTune（Signalsmith Stretch / WORLD / RMVPE / librosa / pyworld ほか）は
すべてMIT・BSD・ISC系のパーミッシブライセンスで構成されており、
**スタンドアローン版を商用配布する場合でもライセンス購入は一切不要**。

以下は「シフトエンジンの品質をさらに上げたくなった場合」の任意のアップグレード候補。
現時点の品質ボトルネックはシフトエンジンではなく検出・アライメント判断
（パーミッシブ構成部分）なので、購入判断は実素材でのA/B試聴後で遅くない。

## 1. Rubber Band Library（Breakfast Quay）

高品質タイムストレッチ/ピッチシフト。GPLと商用のデュアルライセンス。
商用ライセンスは**買い切り・ロイヤリティなし・サブスクなし**、プラットフォーム数無制限。

| ライセンス | 価格 | 条件 |
|---|---|---|
| Standard Licence | **£590**（約11〜12万円※） | クレジット表記（著作権表示）が必要 |
| Non-Attribution（小規模） | **£1,490**（約28〜30万円※） | 従業員10名未満の個人/企業。表記不要 |
| Non-Attribution（通常） | £9,320 | 従業員10名以上の企業。表記不要 |

※ £1=190〜200円換算の概算。為替で変動。

- 本プロジェクトの規模なら **Standard £590** か **小規模Non-Attribution £1,490** が該当
- 注意: 当プロジェクトは「クレジット表示義務のある依存を禁止」方針のため、
  方針どおりなら**Non-Attribution（£1,490）が適合**。Standardを選ぶ場合は
  方針側の例外を明文化すること
- 品質はSignalsmith Stretchと同クラス（素材依存の僅差）。購入前に
  GPL版でオフラインA/B試聴が可能（評価のためのGPL利用→購入、が正攻法）
- 出典: [ライセンス一覧](https://breakfastquay.com/technology/license.html) /
  [Rubber Band概要](https://breakfastquay.com/rubberband/)

## 2. zplane élastique SDK

業界標準のタイムストレッチ（主要DAW多数が採用）。ボーカルの明瞭度維持に
定評があり「既製品として最高品質」と評されることが多い。

- **価格は非公開・要見積もり**（メールでの問い合わせ制）
- 一般に買い切りではなく製品/数量ベースの契約。相場感として
  Rubber Bandより一桁高くなる可能性を見込んでおく
- 検討するなら見積もりと評価版の入手が第一歩
- 出典: [zplane Licensing](https://licensing.zplane.de/technology)

## 3. 購入不要が確定しているもの（参考）

| 項目 | 状況 |
|---|---|
| VST3 SDK | v3.8以降MITライセンス化済み。旧Steinberg契約手続きは廃止。無料 |
| iPlug2（将来のプラグイン化） | zlib系。無料・クレジット不要 |
| ONNX Runtime（C++移行時の推論） | MIT。無料 |
| Electron / wavesurfer.js等のGUI系 | MIT/BSD系。無料 |

## 4. 購入以外で注意すべきライセンス（金銭でなく条項の問題）

ニューラル系の**学習済みモデルのウェイト**には「非商用限定」条項付きのものがある
（一部のボコーダー・歌声変換モデル等）。現在使用中のRMVPE/CREPEはMITで問題ないが、
**今後モデルを追加する際はコードではなくウェイトのライセンスを必ず確認**する。

## 購入判断のチェックリスト

1. 実素材でSignalsmith出力に品質不満が残っているか（現状: シフト品質は問題になっていない）
2. Rubber Band GPL版でのA/B試聴で明確な差が聴き取れるか
3. 差があるなら: 小規模Non-Attribution £1,490（クレジット非表示方針を守る場合）
4. それでも不足ならzplaneへ見積もり依頼
