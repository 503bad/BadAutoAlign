# 04. 検出系

## 1. ピッチ検出（F0）

統一インターフェース: 全検出器は共通グリッド（hop=512サンプル間隔）の
PitchTrack {times, f0, voiced, conf} を返す。

| 検出器 | 依存 | 特徴 |
|---|---|---|
| pyin（既定フォールバック） | librosa(ISC) | 追加依存なし。分解能0.1半音・ビン格子を平均律に整列（→03 §6） |
| rmvpe | onnxruntime + ONNXモデル（要指定） | 歌声向け最高精度。16kHz/hop160/128mel/360ビンの標準構成、局所加重平均デコード |
| crepe | torch + torchcrepe（extra） | フォールバック |

- `--detector auto`（既定）: rmvpe → crepe → pyin の順に利用可能なものを選択
- 検出後の共通ゲート（P2対応）: conf ≥ 0.5 ∧ RMS ≥ ゲート ∧ ZCR < 0.35 を
  有声とする。ZCRは無声摩擦音の誤有声化対策

### 速度に関する設計判断

pYINのビタビ計算は O(フレーム数 × ビン数²)。分解能を10セントに保ち
（整列格子でバイアス0のため品質は落ちない）、hop=512とすることで、
3分の楽曲を全パイプライン約40秒で処理する。5セント分解能・hop256の
初期設定では同じ処理に15分以上かかった。精度が必要な場面は
ニューラル検出器（RMVPE）への切替で対応する方針。

## 2. 中帯域エネルギー包絡

300–3000Hzバンドパス（4次Butterworth, zero-phase）→ フレームRMS → dB →
ガウシアン平滑（σ≈15ms）。母音のエネルギーが支配的な帯域で、
タイミング補正のラグ計測（02 §5）と芯検出の両方に使う。

## 3. 音節（モーラ）分割

日本語歌唱の対応付け単位。3種類の境界手掛かりの和集合:

1. **有声化開始点**: 無声子音・息継ぎの後の母音頭（30ms以上持続する有声区間の頭。
   促音等の短い無声ギャップ≤30msは跨いで結合）
2. **母音品質の変化点**: CMVN正規化MFCC＋Δのノベルティ
   （前後60ms平均特徴の距離）のピーク。レガート内の母音遷移を拾う
3. **ピッチ跳躍**: 前後30ms中央値の差 > 0.8半音（同一母音で音高だけ変わる場合）

### 過分割の吸収（重要）

ビブラートや歌い回しでノベルティが定常ノート内部でも発火するため、
「連続していて（隙間<25ms）・同一音高（<0.6半音）・境界にエネルギー谷
（3dB以上の落ち込み）が無い」断片は同一音節としてマージする。
同一音高で歌い直す連続モーラ（「ああ」等）は再アーティキュレーションの
エネルギー谷が境界に現れるため、分割が保持される。

各音節は {onset, end, 音高中央値, 母音特徴重心(MFCC)} を持つ。

## 4. 芯（P-center）検出

音節/ノートの知覚的な頭。2つの手掛かりの**遅い方**を採用し、
探索は頭から250ms以内にクランプ:

1. **ピッチ到達点**: F0がその区間の安定音高（後半60%の中央値）±50セント圏に
   入り30ms以上持続し始めた最初の時刻。しゃくりを構造的に除外する
2. **中帯域エネルギー最速上昇点**: 包絡dBの勾配最大点。窓内の起伏が
   6dB未満（レガート内などで立ち上がりが無い）なら不使用

ガイドとボーカルに**同一の検出器**を適用して非対称バイアスを防ぐ（02 §4）。

## 5. 音素特徴（話者非依存）

CMVN正規化 MFCC(c1..c12)＋Δ の24次元。話者・音色（SynthV vs 生声）の
絶対差は正規化で消え、母音・子音の対比が距離に残る。
音節アライメントの母音特徴距離と、（履歴上の）フレームDTWに使用。
