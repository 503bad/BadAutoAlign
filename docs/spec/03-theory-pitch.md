# 03. ピッチ補正の理論

## 1. 品質要件と基本方針

「素直に実装するとガビガビになる」問題への対策が設計の出発点。
商用品質の要点は (a) 周波数領域処理による位相コヒーレンス、
(b) フォルマントの独立扱い、(c) 無声音を触らないこと、の3つに集約される。

### 使用禁止事項

- librosa.effects.pitch_shift（位相ロックの無い単純STFT位相ボコーダ）
- 単純リサンプリング（ピッチと時間が連動し、フォルマントも移動する）

## 2. スナップしない補正カーブ（中央値オフセット方式）

ノートへの「スナップ」（F0をノート音高へ張り付ける）はケロケロ声化する。
本ツールは**ずれの直流成分だけを取り除き、揺らぎを保存する**:

1. ノート区間ごとに、検出F0（MIDIノート番号スケール）の**中央値**と
   ターゲット音高の差分（オフセット）を求める
2. 補正カーブはそのオフセットの定数（ノート内で一定）。ビブラート・
   しゃくり・微細な揺らぎは差分に含まれず、そのまま保持される
   （Melodyneのドリフト補正相当の考え方）
3. カーブは時間方向にガウシアン平滑（σ=40ms）し、ノート境界の急峻な
   ジャンプを作らない
4. ノート先頭 attack_preserve（既定80ms）は補正強度をランプイン
   （しゃくりの表情を保持）
5. 補正強度 pitch_strength（既定0.85）を乗算。1.0=完全一致より
   自然さを優先できる

中央値を使う理由: ノート内のF0分布はしゃくり・ビブラートで非対称になるが、
中央値は区間の「芯の音高」を頑健に代表する。平均だとしゃくりに引かれる。

### ガード

| ガード | 既定値 | 目的 |
|---|---|---|
| max_correction | 300セント | これ超のオフセットは検出誤り（オクターブ違い等）とみなしスキップ |
| min_correction | 5セント | フレーズ内の最大補正がこれ未満ならフレーズごと素通し（ヌルテスト保証） |
| 低信頼フレーム | conf < 0.5 | ノート内に使えるフレームが無ければスキップ |

オクターブ違いの歌唱（意図的な下ハモ等）は max_correction ガードが拾い、
タイミング側のピッチ照合はオクターブ折返しで許容する——という分担。

## 3. 無声音・ブレスの素通し（ガビつき対策の核）

ガビつきの主因は無声子音（サ行・タ行）とブレスへのシフト適用。

- 有声判定 = 検出器の有声フラグ ∧ 信頼度 ≥ 閾値 ∧ RMSゲート ∧ ZCR < 0.35
- 無声フレームの補正量は0（シフト比1.0で素通し）
- 有声⇔無声の境界はソフトマスク（ガウシアンσ=10ms）でクロスフェード
- 実装上は「補正カーブ × 有声ソフトマスク × ノート被覆ソフトマスク」の積

## 4. curveモード（WAVガイドのF0転写）

WAVガイド時のオプション。ノート中央値オフセットの代わりに、
ガイドのF0カーブとの差分をフレームごとに転写する（ビブラート・しゃくりの移植）。
転写強度は pitch_strength に従う。既定は note モード（オフセットのみ）。

## 5. シフトエンジン

### 5.1 Signalsmith Stretch（第一候補・既定）

周波数領域処理・位相コヒーレンス・タイムストレッチとピッチシフトを同一
エンジンで実行できる（MIT）。**PyPIの python-stretch バインディングは
呼び出しごとに内部で seek/flush するワンショットAPIであり、チャンクごとに
パラメータを変える用途に使えない**ことを検証で確認したため
（チャンク処理と全体処理の結果が不一致）、ヘッダをベンダリングして
薄いC ABIラッパーを自作した（src/vat/native/）。

- ストリーミングAPI: process(in, n_in, out, n_out) のサイズ比が伸縮率を決める。
  hop（512サンプル）ごとに setTransposeFactor を更新して時間変化する
  ピッチシフトを実現。レイテンシ（input+output）はゼロ詰めフラッシュで補償し、
  出力長は入力長と厳密一致
- **固定シード**: 既定コンストラクタは std::random_device でシードされ
  実行ごとに出力が変わるため、再現性（A/B比較・テスト・GUIの再補正）のため
  固定シードで生成する
- フォルマント: 補正量が小さい（≲1半音）用途のため、明示的なフォルマント
  処理は既定で無効（スペクトル包絡推定による副作用を避ける）。
  大きなシフトを扱う場合は setFormantFactor の有効化を検討

### 5.2 WORLD（比較・フォールバック）

F0/スペクトル包絡/非周期性に分解し、F0のみ差し替えて再合成（修正BSD）。
フォルマント＝包絡が構造的に保持される。タイムワープはフレーム列の
リサンプリングで実現（F0は有声性を保つ最近傍＋有声同士のみ対数補間）。
ブレスがビジーになる既知の癖があるためA/B用。--engine world で切替。

## 6. 検出グリッドの平均律整列（実装上の重要な工夫）

pYINの周波数ビンは fmin から resolution 刻みで構成される。fmin=65Hz（非整列）だと
ビン中心が平均律から最大±5セント級にずれ、**検出自体に系統バイアス**が乗る
（実測でC4に-4.2セント）。fmin = C2 = 65.40639Hz とすることでビン格子が
平均律に整列し、正しい歌唱に対する検出オフセットが0になる。
これにより10セント分解能でも中央値オフセット方式の品質要件
（残差<10セント）を満たし、5セント分解能比で検出が約4倍高速になる。
